## Summary
I spent some time working on this postal map for the past couple weeks, and I am finally finished with it. This only includes the YTDs and the radar zoom, not the PSD for the actual map.
Here is the free release.

## Install
1. Choose the map of your choice (one has highway markers and one has no markers, just postals and streets)
2. Copy and paste all YTDs of your choice into `postal_map/stream`
3. Drag the `postal_map` resource into your server and restart the server
